# Procedure completeness requires explicit boundary evidence

A procedure is complete only when a configured end marker follows its final
step or, for a reviewed profile using the section-boundary strategy, the next
heading is at the same or a shallower level than the procedure heading. A deeper
heading makes ownership of the following content ambiguous, and a later peer
heading does not resolve that ambiguity. Documents that simply end, procedures
that begin after step 1, and procedures with duplicate or discontinuous steps
remain partial.

We require the section-boundary strategy to name a maintainer review because
heading proximity alone cannot establish that a PDF section contains every
step. The artifact records the accepted start and end boundaries plus the
strategy used, while navigation text that contradicts completeness remains
visible as an audit note. This deliberately gives up coverage for uncertain
layouts rather than presenting a fragment as a complete safety procedure.
